### 🏢 Création d'entreprise (5 étapes)
**Accès :** Dashboard → "Créer entreprise"

```
Étapes :
1️⃣ Informations de l'entreprise
   - Nom, forme juridique, siège social...

2️⃣ Documents légaux
   - Upload CNI, casier judiciaire...

3️⃣ Libération du capital
   - Associés et répartition
   - Libération totale/partielle
   - Montant et pourcentage

4️⃣ Signature électronique
   - Dessinez votre signature
   - Documents à signer

5️⃣ Validation finale
   - Résumé complet
   - Confirmation et paiement
```

## 🎯 Raccourcis rapides

### Client Mobile
| Pour faire | Cliquer sur |
|------------|-------------|
| Créer entreprise | Dashboard → Carte "Créer entreprise" |
| Signer documents | Dashboard → "Signature & Validation" |
| Valider document | Signature & Validation → Document → "Valider" |
| Rejeter document | Signature & Validation → Document → "Rejeter" + commentaire |
| Voir livrables | Dashboard → "Branding" → Projet |
| Prendre RDV | Bottom bar → RDV |
| Voir timeline | Bottom bar → Dossiers |

### Client Web
| Pour faire | Cliquer sur |
|------------|-------------|
| Créer entreprise | Dashboard → Carte "Création d'entreprise" |
| Signer documents | Dashboard → Carte "Signature & Validation" |
| Valider document | Menu "Signature" → Document → "Valider" |
| Voir livrables | Menu → "Branding" → Projet |

### Admin
| Pour faire | Cliquer sur |
|------------|-------------|
| Voir documents à corriger | Menu → "Documents" → Onglet "À corriger" |
| Corriger un document | Document rejeté → "Corriger" |
| Uploader nouvelle version | Modal correction → Upload + Note → "Soumettre" |
| Voir livrables clients | Menu → "Branding" → Projet client |

## 📱 Bottom Bar Mobile (toujours visible)

```
┌─────────┬─────────┬─────────┬─────────┐
│  🏠     │   📅    │   📊    │   📄    │
│ Accueil │   RDV   │ Dossiers│Documents│
└─────────┴─────────┴─────────┴─────────┘
```

**Fonctions :**
- **Accueil** : Retour au dashboard
- **RDV** : Prendre rendez-vous pour signature
- **Dossiers** : Timeline de tous vos dossiers
- **Documents** : Accès aux documents finalisés

## ✨ Badges et notifications

### 🔴 Badge rouge avec chiffre
= Nombre d'actions en attente
- Exemple : **[3]** = 3 documents à signer/valider

### 🟣 Badge violet
= Document en attente de validation

### 🟢 Badge vert
= Document/livrable validé

### 🟠 Badge orange
= Document à corriger (rejeté)
