## ❓ FAQ - Questions Fréquentes

### Q : Combien de boutons "Enregistrer et quitter" y a-t-il ?
**R :** Il y a **3 boutons par page** :
- 1 bouton flottant fixe (toujours visible)
- 1 badge auto-save dans le header
- 1 gros bouton dans la bannière en bas

### Q : Pourquoi 3 boutons ?
**R :** Pour garantir que vous ne les manquiez JAMAIS, quel que soit :
- L'endroit où vous regardez
- Si vous scrollez ou non
- Votre taille d'écran

### Q : Les boutons sont-ils visibles sur toutes les étapes ?
**R :** OUI ! Les 3 boutons sont présents sur chacune des 5 étapes du processus.

### Q : Que se passe-t-il si je clique sur "Enregistrer et quitter" ?
**R :** 
1. Toutes vos données sont sauvegardées
2. Vous recevez une notification de confirmation
3. Vous êtes redirigé vers le dashboard après 800ms
4. Vous pouvez reprendre plus tard exactement où vous étiez

### Q : Les boutons fonctionnent-ils hors ligne ?
**R :** Les boutons sont toujours visibles, mais la sauvegarde nécessite :
- Un utilisateur connecté
- Les données sauvegardées en local (localStorage)

### Q : Puis-je sauvegarder plusieurs fois ?
**R :** OUI ! À chaque clic :
- Si c'est un nouveau brouillon → Création
- Si le brouillon existe déjà → Mise à jour (pas de duplication)
