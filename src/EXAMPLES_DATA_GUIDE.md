## 🔍 Filtrage automatique

Le code filtre automatiquement pour n'afficher que les sociétés finalisées :

```typescript
const completedCompanies = companies.filter(
  (c) => c.userId === currentUser?.id && c.status === 'completed'
);
```

### **Critères de filtrage**
1. ✅ `userId` correspond à l'utilisateur connecté
2. ✅ `status === 'completed'` uniquement
3. ❌ Exclut les statuts : `draft`, `submitted`, `in_review`, `documents_ready`, `signed`

## 💡 Ajout de nouvelles sociétés d'exemple

### **Template pour ajouter une société**

```typescript
{
  id: 'unique-id',
  name: 'Nom de la Société [Forme]',
  legalForm: 'SARL' | 'SA' | 'SAS' | 'SCI' | 'SUARL' | 'SNC',
  activity: 'Secteur d\'activité détaillé',
  capital: 1000000, // En FCFA
  address: 'Adresse complète, Quartier, Ville',
  clientId: '1', // ID de l'utilisateur
  userId: '1', // Même que clientId
  status: 'completed', // Pour qu'elle apparaisse dans "Mes sociétés"
  createdAt: '2024-XX-XXT10:00:00Z',
  updatedAt: '2024-XX-XXT14:30:00Z',
}
```

### **Bonnes pratiques**
- ✅ Utilisez des noms sénégalais authentiques
- ✅ Variez les secteurs d'activité
- ✅ Respectez les minimums de capital par forme
- ✅ Utilisez des adresses réelles de Dakar
- ✅ Ajoutez `userId` ET `clientId` pour compatibilité

## 🐛 Debugging

### **Problème : Société n'apparaît pas**

Vérifier :
1. ✅ `status === 'completed'`
2. ✅ `userId === currentUser?.id`
3. ✅ `clientId === currentUser?.id` (compatibilité)
4. ✅ Société présente dans `mockCompanies`

### **Problème : Mauvais nombre de sociétés**

```typescript
// Compter les sociétés par utilisateur
const user1Companies = companies.filter(c => 
  (c.userId === '1' || c.clientId === '1') && c.status === 'completed'
);
console.log(user1Companies.length); // Devrait afficher 5

const demoCompanies = companies.filter(c => 
  (c.userId === 'client-demo' || c.clientId === 'client-demo') && c.status === 'completed'
);
console.log(demoCompanies.length); // Devrait afficher 3
```
