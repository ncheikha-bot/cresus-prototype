## 🎯 Points d'attention visuels

### 1. Section conjoint DOIT ressortir
```
✓ Fond doré distinct du blanc
✓ Icône 👥 visible immédiatement
✓ Bordure subtile mais présente
✓ Padding généreux pour aération
```

### 2. Hiérarchie visuelle
```
1. Nom de l'associé (titre)
2. Champs de base (standard)
3. Situation matrimoniale (section)
4. Infos conjoint (emphase dorée)
```

```
Hover   → Légère opacité sur select
Focus   → Ring doré + border doré
Active  → Couleur texte plus foncée
Disabled→ Opacité 50% + cursor-not-allowed
```

## ✨ Micro-interactions

### Select dropdown
```
Au clic :
1. Dropdown s'ouvre avec animation (150ms)
2. Options avec hover effect (bg-[#D6A93A]/10)
3. Sélection → fermeture (100ms)
4. Valeur affichée avec fade-in
```

### Apparition champs conditionnels
```
Nouveau champ visible :
1. Opacity: 0 → 1 (200ms)
2. Transform: translateY(-5px) → 0 (200ms)
3. Height: auto expansion
```

### Focus sur input
```
Sur focus :
1. Border: transparent → #D6A93A (100ms)
2. Ring: apparition avec scale (150ms)
3. Label: color #273A7A/60 → #273A7A (100ms)
```
