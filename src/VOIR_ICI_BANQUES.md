## 🎉 Accès Direct - Aucun Identifiant Requis !

**L'espace banque est accessible sans connexion.**  
Cliquez simplement sur la carte verte "Espace Banque" et vous êtes directement dans le dashboard !

Par défaut, vous accédez au compte **Bank of Africa** avec toutes les demandes visibles.

---

## ⚡ Actions Rapides

### En tant que Banque

**Voir les demandes**
```
Dashboard → Liste des demandes
```

**Filtrer**
```
Dashboard → Boutons filtres (Nouveaux, En revue, etc.)
```

**Rechercher**
```
Dashboard → Barre de recherche
```

### En tant qu'Admin

**Créer une banque**
```
Admin → Banques → + Ajouter une banque
```

**Modifier une banque**
```
Admin → Banques → Icon crayon (✏️)
```

**Activer/Désactiver**
```
Admin → Banques → Icon vert/rouge
```
